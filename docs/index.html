Operant conditioning changes the spinal cord. We asked whether the cortex carries a signal about the reflex on individual trials — and built the controls to find out whether the answer was real.

What actually explains reflex size

Cortex and stimulus share variance, because the stimulus drives both the cortical evoked response and the reflex. Only the non-overlapping part counts.

Why the headline number went down, not up

An earlier estimate put the cortical share far higher. That version removed the stimulus across all trials at once and then measured cortex block by block, which leaves between-block stimulus variance behind — and cortex tracks the stimulus. Removing it inside each block gives 0.037. It is the smaller claim, and the one that survives.
